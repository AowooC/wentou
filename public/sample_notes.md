# 普通心理学 第5讲 学习与记忆（课堂笔记）

## 一、学习
- 学习就是经验导致的行为变化。
- 巴甫洛夫的狗：铃声+食物 → 狗听到铃声就流口水。这是经典条件反射。
- 斯金纳箱：老鼠按杠杆得到食物，以后按得更多，这是操作性条件反射。
- 经典条件反射和操作性条件反射其实差不多，都是建立联系。
- 负强化就是惩罚，所以会让行为减少。
- 消退以后行为就彻底没了，显然原来的联结被删除了。
- 间歇强化比连续强化效果好，赌博机就是例子。
- 泛化和分化：小阿尔伯特怕白鼠后也怕兔子，这叫泛化，分化反过来。
- 观察学习（班杜拉）：小孩看大人打波波玩偶就会模仿，说明不需要强化也能学习。

## 二、记忆
- 记忆分三个阶段：感觉记忆、短时记忆、长时记忆。
- 工作记忆就是短时记忆，换个名字而已。
- 短时记忆容量是7±2，所以人一次只能记7个东西。
- 复述可以让信息进入长时记忆，但老师说保持性复述和精细复述不一样，没听清。
- 加工水平理论：加工越深记得越好。
- 遗忘曲线：先快后慢。因此复习要趁早。
- 艾宾浩斯用的是无意义音节，这个很重要。
- 编码特异性原则：提取时的情境和编码时一致记得更好，老师举了潜水员的例子。
- 前摄抑制和倒摄抑制，一个是旧的干扰新的，一个是新的干扰旧的（哪个是哪个？）。
- 长时记忆是永久的、容量无限。
